DnD 5.5e All-in-One BEYOND

DnD 5.5e All-in-One BEYOND는 D&D 5.5e를 바탕으로 한 규칙, 플레이어 선택지, 주문, 재주, 장비, 직업 개편을 하나로 묶은 발더스 게이트 3 올인원 모드입니다.

직업과 하위 직업, 주문, 재주, 배경, 종족, 전투 방식, 무기 숙련술을 검색과 필터로 찾아볼 수 있는 데이터 브라우저를 만들었습니다. 모든 내용은 모드 게임 데이터에서 생성합니다: 데이터 브라우저
